## Sistema de livraria online

Este projeto foi desenvolvido utilizando armazenamento de dados em memória e contém todas as operações CRUD (Create, Read, Update, Delete) completas.

---

## 🚀 Tecnologias Utilizadas

- **Python 3.x**
- **FastAPI** 
- **Pydantic** 

---

## ⚙️ Como rodar o projeto localmente

**1. Clone o repositório:**
```bash
git clone [https://github.com/raffaela09/fastapi_pydantic.git](https://github.com/raffaela09/fastapi_pydantic.git)
cd fastapi_pydantic
2. Crie o ambiente virtual:

Bash
python -m venv venv
3. Ative o ambiente virtual:

PowerShell
.\venv\Scripts\Activate.ps1
4. Instale as dependências:

Bash
pip install -r requirements.txt
5. Execute a aplicação:

Bash
fastapi dev main.py
